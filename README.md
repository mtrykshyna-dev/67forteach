# SIX SEVEN — інтернет-магазин одягу

Шкільний проєкт: статичний інтернет-магазин на HTML, CSS та JavaScript без сервера.

## Можливості

- каталог із категоріями, пошуком, фільтром за розміром і сортуванням;
- сторінка товару з галереєю, таблицею розмірів (одяг, джинси, взуття) і підбором розміру;
- відгуки й коментарі до товарів;
- кошик, обране, нещодавно переглянуті;
- оформлення замовлення з вибором міста й відділення;
- реєстрація, вхід та історія замовлень.

Дані (кошик, акаунти, замовлення, відгуки) зберігаються в `localStorage` браузера.

## Як запустити

Відкрийте `index.html` у браузері.

## Структура

- `*.html` — сторінки сайту;
- `CSS/` — стилі;
- `JavaScript/data.js` — товари, категорії, розмірні сітки;
- `JavaScript/store.js` — спільна логіка (кошик, обране, акаунти, відгуки);
- `img/` — зображення.
